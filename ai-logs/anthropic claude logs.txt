def tokenise(text, lang):
    doc = tokenisers[lang](text)

    tokens = []
    offsets = []

            tokens.append(token.text)
            offsets.append((token.start_char, token.end_char))

    return tokens, offsets


def tokenise_context_and_answer(context, answer, lang):
    context_tokens, context_offsets = tokenise(context, lang)

Q: how to add page number

A: With the ACL `final` option, page numbers are off. The `review` option adds them, but it also adds line numbers and anonymises authors, so don't use it for the final PDF.

\pagestyle{plain}

If that has no effect (the ACL style can reset the page style), use this instead:

```latex
\usepackage{fancyhdr}
\fancypagestyle{plain}{\fancyhf{}\fancyfoot[C]{\thepage}\renewcommand{\headrulewidth}{0pt}}
\pagestyle{plain}
\AtBeginDocument{\thispagestyle{plain}}
```

The `\AtBeginDocument` line is there because the first page uses its own style. Without it, page 1 may stay unnumbered.

A: Your groupmate's work is `src/integrated_qa.py` plus `notebooks/7_integrated_multilingual_qa.ipynb`. It covers Weeks 40–41: a fine-tuned XLM-R question-answering model that predicts a span or "no answer".

## What it does

1. **Model.** `xlm-roberta-base` with a QA head (`AutoModelForQuestionAnswering`), trained as one joint model on Arabic, Korean and Telugu. The encoder is frozen except for the last 4 Transformer layers and the head.
2. **Input.** Question and context are encoded as a pair, truncating only the context. It uses 384 tokens with a stride of 128, so long contexts become several windows.
3. **Labels.** For each window, the start and end tokens are the answer's character offsets mapped to tokens. If the answer isn't in the window, or the question is unanswerable, both point to token 0 (`<s>`). Token 0 therefore means "no answer".
4. **Training.** AdamW with learning rate 2e-5, weight decay 0.01 and 200 warmup steps. It runs 10 epochs at batch size 4, about 16k steps, on all training data, with seed 42. Loss falls from 2.92 to 0.65. The checkpoint is saved to `checkpoints/integrated_qa`.
5. **Prediction.** For each question it takes the best span across windows, scored as start logit plus end logit, with spans of at most 30 tokens. The no-answer score is the null score minus the best-span score. The null score is the window's score on token 0, minimum over windows. If that score is above the threshold, the model outputs an empty answer.
6. **Threshold.** It sweeps 100 values on the validation set and keeps the one with the best token F1, which is −5.90.
