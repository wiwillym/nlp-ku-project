# Multilingual Question Answering – NLP Course Project

## Project Overview

This repository contains the code and experiments for our Natural Language Processing (NLP) course project at the University of Copenhagen.

The project focuses on multilingual question answering (QA), investigating how machine learning models can extract answers from context passages in different languages.

We work with three languages:

- **Arabic (ar)**
- **Korean (ko)**
- **Telugu (te)**

The project investigates multilingual question answering using XLM-R across Arabic, Korean, and Telugu.

## Technologies and Libraries

The project uses the following technologies and Python libraries:

- **Python** – Main programming language.
- **PyTorch** – Model training and implementation.
- **Hugging Face Transformers** – Pre-trained multilingual models.
- **XLM-RoBERTa (`xlm-roberta-base`)** – Main multilingual question-answering model.
- **Hugging Face Datasets** – Dataset loading and handling.
- **Stanza** – Text tokenisation and preprocessing.
- **Pandas** – Data manipulation and analysis.
- **NLLB** – Multilingual machine translation experiments.
- **Google Colab / Jupyter Notebook** – Running experiments and training models.

## Running the Project in Google Colab

The notebooks were primarily developed and executed using Google Colab.

To run the experiments:

1. Open the required notebook from the `notebooks/` directory.
2. Upload the notebook to Google Colab or open it from the repository.
3. Make sure the required dependencies are installed.
4. Run the notebook cells in order.

### Prepare the data

Run the notebooks in the following order:

1. `1_data_downloading.ipynb` – Downloads the required datasets.
2. `2_preprocessing.ipynb` – Prepares and tokenises the data.

### Training Configuration

The Integrated QA, Question Translation, and Zero-Shot Telugu notebooks include a `RUN_TRAINING` variable to control whether model training is performed.

- Set `RUN_TRAINING = True` to execute the model training process.
- Set `RUN_TRAINING = False` to skip the training steps.

Some notebooks depend on datasets, preprocessing outputs, or files generated by earlier notebooks.

GPU acceleration may be required for model training.

## Source Code

The `src/` directory contains reusable Python modules used by the notebooks. These modules handle data-related functionality, preprocessing and integrated QA implementation.
